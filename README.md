# 🚀 Desafio DIO - Criação e Configuração de Máquina Virtual no Azure

## 📘 Entendendo o Desafio

Este repositório faz parte do desafio prático proposto pela DIO, com o objetivo de **documentar o processo de criação e configuração de uma máquina virtual (VM) na plataforma Microsoft Azure**, aplicando os conhecimentos adquiridos nas aulas e reforçando a compreensão dos temas discutidos.

## 🎯 Descrição do Desafio

O laboratório propõe a criação de uma **máquina virtual no Azure** seguindo as boas práticas, por meio do portal da Microsoft. O entregável consiste em um repositório contendo:

- ✅ Resumo dos passos realizados
- 📝 Anotações técnicas relevantes
- 💡 Dicas úteis sobre o uso da plataforma Azure

> Referência oficial utilizada:  
> [Criar uma máquina virtual Windows no portal do Azure](https://learn.microsoft.com/pt-br/azure/virtual-machines/windows/quick-create-portal)

## 🧠 Objetivos de Aprendizagem

Ao final deste desafio, você será capaz de:

- Aplicar os conceitos aprendidos em um ambiente prático de nuvem;
- Documentar processos técnicos de forma clara e estruturada;
- Utilizar o GitHub como ferramenta de versionamento e compartilhamento de conhecimento técnico.

## 📌 Etapas Realizadas

1. Acesso ao [portal do Azure](https://portal.azure.com/)
2. Criação de um novo recurso do tipo **Máquina Virtual**
3. Definição de configurações básicas (nome, região, imagem, tamanho, autenticação)
4. Configuração de regras de segurança (porta RDP habilitada)
5. Criação e execução da VM
6. Acesso remoto via RDP
7. Documentação de todo o processo neste repositório
