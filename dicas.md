# Dicas de Uso do Azure para Máquinas Virtuais

## 🔐 Segurança

- Alterar a porta padrão RDP (3389) reduz riscos de ataques automatizados.
- Crie regras de firewall mais restritivas com base no IP do seu provedor de internet.
- Use **Autenticação Multi-Fator (MFA)** para o login na conta Azure.

## 💰 Custo

- Use o tamanho de VM mais enxuto possível para testes (por exemplo, B1s).
- Desligue a VM quando não estiver utilizando para evitar cobrança contínua.
- Configure alertas de orçamento no portal Azure.

## 🛠️ Gerenciamento

- Utilize o **Azure Resource Group** para agrupar todos os recursos da VM.
- Crie **Snapshots** ou **Backup** da VM antes de alterações críticas.
- Use **Tags** para facilitar a organização de recursos.
